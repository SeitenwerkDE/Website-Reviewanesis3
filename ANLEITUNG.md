# ANESIS Website – Upload für GitHub-Repository "Website-Reviewanesis3"

Diese Version funktioniert NUR im Repository mit dem Namen Website-Reviewanesis3
Adresse: https://seitenwerkde.github.io/Website-Reviewanesis3/

1. Im Repository alle alten Dateien und Ordner löschen.
2. ZIP entpacken.
3. Add file -> Upload files -> Ordner "assets" hineinziehen -> Commit changes.
4. Add file -> Upload files -> alles andere hineinziehen
   (index.html, 404.html, .nojekyll, favicon.svg, robots.txt, sitemap.xml,
   Ordner speisekarte, impressum, datenschutz, downloads) -> Commit changes.
5. 2 Minuten warten, Seite öffnen, Strg+F5 drücken.

Wird das Repository umbenannt, muss die Website neu gebaut werden.
